# 会话内虚拟桌面监视与接管设计

## 目标

将 `dsh-vdesktop` 从全局右下角浮窗迁移到 DSH 会话头部的 `conversation.view` 标签页。每个会话有独立的虚拟桌面监视环境，可在完整内容区域查看大图、操作日志，并在明确接管后使用鼠标和键盘操作。完成后验证本地插件，再以 `dsh-vdesktop@0.2.0` 发布到 npm。

## 范围与兼容

- 保留现有 `vdesk_*` 和 `browser_*` 工具名称、参数与基本返回结构。
- 新标签页名为“虚拟桌面”，位于“轨迹”之后；支持中英文文本。
- 仅支持 Windows x64；发布包包含预编译 `dshv.exe`，不发布 Rust 构建缓存、测试证据或临时截图。
- 浏览器操作采用独立的无头 Chromium 会话，不访问用户的浏览器配置或登录凭证。
- 不提供任意远程控制页面、跨会话桌面共享或额外业务功能。

## 方案

### 1. 会话归属与运行环境

- 使用 `ctx.agents.currentInitiator()` 在工具执行边界获得会话 id；没有明确会话的调用不进入某个会话的监视器，也不默认归到最近使用的会话。
- 每个会话拥有独立的桌面名称空间、无头浏览器、操作日志、最后画面和手动接管状态。用户只需向 Agent 提供逻辑桌面名，Host 将其映射到当前会话拥有的实际桌面。
- 会话首次调用工具时才创建运行环境；会话释放或插件卸载时清理相应 sidecar、浏览器进程、套接字及监听器。
- 一个会话的日志与画面只推送给该会话的标签页。不得因另一个会话调用工具而切换当前画面。

### 2. 会话内标签页

- Client 通过 `conversation.view` 注册 `virtual-desktop`，通过插槽提供的 `sessionId` 和订阅接口选择当前会话的数据。
- 移除 `shell.overlay` 浮窗。标签页使用 Host 主题令牌，在剩余内容区域展示自适应大图；宽屏时操作记录位于右侧，窄屏时位于下方。
- 顶栏提供桌面选择、连接状态、观看/接管状态和“交还 Agent”。日志显示时间、工具、摘要、耗时和成功/失败状态。
- 无桌面时显示操作提示；连接断开时保留已有信息并显示重连状态，不能把旧画面误标为实时。
- WebSocket 只发送当前会话拥有的帧和日志，页面切换后停止不需要的连接和订阅。

### 3. 鼠标与键盘接管

- 默认是“观看”模式，点击、按键不控制目标应用。
- 用户点击“接管操作”后，当前会话进入手动模式；Agent 的 `vdesk_*`、`browser_*` 调用被明确拒绝，并提示先交还控制。其他会话不受影响。
- 在画面上的左键、双击、右键、拖拽、滚轮按缩放后的图像坐标换算为目标窗口或浏览器视口坐标，复用现有 sidecar / CDP 控制路径。
- 键盘输入只在接管模式且画面获得焦点时生效。支持文本、中文、常用功能键和 Ctrl 组合键；不让普通输入冒泡到会话编辑器。浏览器保留系统级快捷键，不尝试全面替代原生桌面。
- 同一操作只走一条 Host 控制入口，供 UI 与工具复用。操作失败显示具体原因，不宣称已执行。
- 点击“交还 Agent”立即退出手动模式；关闭标签页、会话销毁或连接失效时也退出，确保 Agent 不会无限期被锁住。

### 4. 状态与推送

- Host 维护每会话的操作日志（上限 50 条）、最新桌面画面及连接诊断。
- 工具执行记录归属调用会话。截图只在工具操作后捕获；画面未变化时抑制重复推送。
- 优先评估现有会话投影作为日志来源；实时图像仍使用按会话过滤的 WebSocket。不得发明新的不可忽略 Session 事件。
- 截图预览可提升分辨率，但保留传输上限，避免大图频繁阻塞会话。

## 发布

- 包名 `dsh-vdesktop`，版本 `0.2.0`，移除 `private`，补全公开包所需的许可证、说明、关键词与平台字段。
- 使用现有 npm 登录身份发布；发布前检查包名占用、npm registry、登录状态和 `npm pack` 文件清单，不输出或读取 token。
- 更新 README 的安装、会话标签页、手动接管和限制说明。
- 通过 `plugin_manager` 安装更新并启用插件，检查真实 `conversation.view` 注册和 Host 工具；重启要求是安装流程的一部分。

## 验证与完成标准

1. JavaScript 语法、JSON、YAML、Rust 构建与已有测试通过。
2. 新增会话隔离、桌面名称映射、手动锁、坐标换算及生命周期测试。
3. 两个会话的工具调用不会混入彼此的监视记录、浏览器或桌面环境。
4. 观看模式不执行操作；接管模式阻止本会话 Agent 操作；交还后恢复，其他会话不受影响。
5. 用记事本验证真实桌面的大图、点击、中文输入与关闭；用无头浏览器验证网页点击、文本输入及截图。
6. 在已连接的 DSH 页面检查标签页、画面布局、主题、焦点与卸载行为；没有浏览器控制能力时明确报告未完成的视觉验证。
7. 检查 npm 打包清单后发布；只有 registry 返回可查询的新版本才称发布成功。

## 明确不做的内容

- 不改变隐藏的 Win32 桌面技术路线，不承诺支持已记录为不可捕获的 Chromium / WebView2 桌面程序。
- 不修改现有会话消息或 DSH 内置标签页。
- 不自动初始化或提交现有源码到 Git：当前目录不是 Git 仓库，因此设计文档无法按 Git 工作流提交。
